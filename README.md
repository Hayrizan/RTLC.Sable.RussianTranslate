# RTLC.Sable.RussianTranslate

Русская локализация **Sable** для Windows x64 / Steam, Unity **2020.3.35f1**. Версия русификатора — **2.3.1**. Плагин работает с BepInEx **6.0.0-pre.1 IL2CPP/Unhollower**.

## Установка

1. Скачайте [готовый ZIP с BepInEx из последнего релиза](https://github.com/Hayrizan/RTLC.Sable.RussianTranslate/releases/latest).
2. Закройте игру и распакуйте содержимое архива **в папку с `Sable.exe`**. В Steam: свойства игры → установленные файлы → обзор.
3. Запустите Sable обычным способом через Steam.

При первом запуске BepInEx автоматически создаёт библиотеки совместимости: этот запуск может быть дольше обычного. Базовые библиотеки Unity уже включены в полный ZIP, скачивание отключено. Если русификатор используется впервые, выбирается русский; ранее сохранённый выбор языка сохраняется.

```text
Sable/
├── Sable.exe                         # уже установленная игра
├── winhttp.dll
├── doorstop_config.ini
├── mono/
└── BepInEx/
    ├── core/
    ├── config/BepInEx.cfg
    ├── unity-libs/
    └── plugins/RTLC.Sable.RussianTranslate/
        ├── RTLC.Sable.RussianTranslate.dll
        └── rtlc.bundle
```

В папке самого русификатора нужны только DLL и бандл. Перед установкой поверх других модов сохраните их загрузчик и настройки: полный ZIP содержит BepInEx и заменяет файлы совпадающих имён. Варианты загрузчика на Il2CppInterop несовместимы с этим плагином на Unhollower.

Диагностика — в `BepInEx/LogOutput.log`. Консоль выключена, мгновенная запись каждой строки лога отключена. Если перевод не появился, проверьте вложенность папок и выбранный язык.

Для удаления только перевода выберите English, выйдите из игры и удалите `BepInEx/plugins/RTLC.Sable.RussianTranslate`. Общие файлы BepInEx и Mono удаляйте лишь тогда, когда они не нужны другим модам. Сохранения игры удалять не нужно.

## Содержимое проекта

- Интерфейс, диалоги, повествование, задания, названия и описания предметов.
- Кириллические шрифты с сохранением оригинальных гарнитур там, где это возможно.
- Два локализованных логотипа, предоставленных автором проекта.
- Единый исходник перевода: [`Translations/translation.txt`](Translations/translation.txt).

Названия и решения по персонажам описаны в [глоссарии](Docs/Sable_Translation_Glossary.md) и [справочнике персонажей](Docs/Character_Gender_Reference.md). В частности, Сэйбл и Сарин — женского рода, Хилал и Утарий — мужского. Название профессии «картограф» не меняется в зависимости от пола.

## Сборка из исходников

Для DLL нужны .NET SDK, установленная Sable и BepInEx указанной версии с уже подготовленной папкой `BepInEx/unhollowed`. Игровые DLL, Mono и BepInEx в Git не хранятся.

Задайте переменную `SABLE_GAME_PATH`, указывающую на папку с `Sable.exe`, затем выполните:

```powershell
dotnet build -c Release
```

Путь также можно передать свойством MSBuild `SableGamePath` или задать в локальном, исключённом из Git файле `Directory.Build.local.props`.

Для бандла нужна **Unity Editor 2020.3.35f1**. Python-инструменты устанавливаются отдельно:

```powershell
python -m pip install -r tools/requirements.txt
python tools/extract_game_fonts.py "$env:SABLE_GAME_PATH"
$env:UNITY_EDITOR_PATH = Read-Host 'Путь к Unity 2020.3.35f1/Editor/Unity.exe'
./tools/build_bundle.ps1
python tools/validate_bundle.py
```

Исходные Euclid/SangBleu извлекаются **локально из вашей копии игры** в `Fonts/Original`, исключённую из Git. Они не включены в открытый репозиторий. Подробнее — [о шрифтах](Docs/OriginalTypography.md). Список ресурсов бандла задан в `tools/bundle-fonts.json`: 21 шрифт, 2 логотипа и перевод. Результат — `build/bundle/rtlc.bundle`; DLL находится в `bin/Release/netstandard2.1`.

Для полного ZIP положите официальный `BepInEx_UnityIL2CPP_x64_6.0.0-pre.1.zip` в `build/dependencies`, затем укажите каталог базовых Unity-библиотек из рабочей установки:

```powershell
python tools/build_release.py --unity-libs "$env:SABLE_GAME_PATH/BepInEx/unity-libs"
```

Архив создаётся в `dist`. Скрипт не перезаписывает существующий релиз. Результаты сборки, зависимости и локальные материалы тестирования в Git не включаются.

## Редактирование перевода

```text
###Главное меню
#@ui:TitleScreen_ContinueGame_Text
Continue=Продолжить
```

Редактируйте русский текст справа от первого неэкранированного `=`. Сохраняйте английский оригинал, `#@`-идентификаторы, теги, переменные и управляющие последовательности. Переносы записываются как `\n`, знак равенства — `\=`, обратная косая черта — `\\`. Перемещайте запись вместе с её меткой.

После правок пересоберите и установите бандл, затем перезапустите игру. Установленные свободные TXT/PNG/шрифты не переопределяют бандл. Исходники логотипов — `Textures/SableLogo01.png` и `Textures/SableLogoWhite01.png`, RGBA 2048×999.

## Проверки

```powershell
dotnet run --project tests/RegressionTests.csproj -- Translations/translation.txt
```

Автономные тесты требуют .NET SDK 10; сама игра для них не нужна. Для версии 2.3.1 пройдена 91 проверка. Полный каталог содержит 5530 записей. Содержимое бандла сверяется с исходниками, целостность ZIP проверяется перед публикацией.

Холодный запуск готового ZIP на чистой установке Sable не выполнялся. Это ограничение не заменяется проверками сборки. Обновления игры, другие версии Unity и загрузчики требуют повторной проверки.
