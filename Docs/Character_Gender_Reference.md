# Sable — справочник персонажей и согласования

Справочник фиксирует согласование персонажей, включая редакционные решения для английских `they/them` и нейтрального `it`, когда они относятся к конкретному персонажу. Если Ink не задаёт род, в русском выбираем мужской или женский по имени, внешнему образу и манере персонажа; после выбора последовательно используем соответствующие местоимения и формы глаголов. Множественное `they` о группе остаётся множественным числом. Для каждого такого решения указываем исходное местоимение и выбранный род в заметке персонажа. Должность Cartographer всегда переводим как «картограф», даже для женщин; женский род выражаем местоимениями и формами глаголов.

## Правила для спорных местоимений

- В дневнике Сэйбл первое лицо всегда согласуется с женским родом, даже если исходная английская фраза не маркирует пол: «я заметила», «я была», «я уверена».
- Если `they/their` относится к известному мужчине или женщине, использовать его или её форму из таблицы. Например, для Хилала — «он», «его», «сказал».
- Для персонажа, обозначенного в оригинале единственным `they/them` или нейтральным `it`, выбирать мужской или женский род по имени, внешнему образу и манере речи, затем последовательно согласовывать все упоминания. В частности, Утарий — мужской, Сарин — женский; Зеби — мужской, Сола — женский. В заметке каждого персонажа фиксировать исходное местоимение и редакционный выбор.
- Если `they` обозначает нескольких людей, переводить во множественном числе: «они», «их», «сказали».
- Для безымянных или действительно неидентифицированных собеседников предпочитать перестройку без рода: «мне ответили», «голос звучал», «собеседник сказал» — выбирать вариант по реальному контексту сцены.
- Не переносить род одного персонажа на одинаковую английскую фразу в другой ветке: сверять точный `#@ink`-путь и говорящего.

## Проверка источников

Имена и контекст сверяются с сюжетным Ink из установленной игры. Для Алтына и Утария дополнительной проверкой послужил [справочник персонажей и местоимений Sable](https://ludonarrative.neocities.org/sable/sable_characters); Элиисабет также подтверждается как бывшая стражница в [руководстве по заданиям](https://thegamesedge.com/sable-walkthrough-guide/).
Дополнительное примечание по источникам: независимый справочник Ludonarrative помечает Утария как `they/them`, но для русской версии действует решение автора перевода: Утарий — мужчина. Сарин в этом справочнике отсутствует; для установленного перевода сохраняется заданный женский род. Внешние гайды и визуальное описание не переопределяют эти решения.
