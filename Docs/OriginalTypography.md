# Шрифты оригинальной игры

В `Sable_Data/data.unity3d` находятся исходные Font-ресурсы EuclidFlex, EuclidTriangle и SangBleuVersailles. Подготовленные игровые TMP-атласы могут не содержать полный набор русских букв, хотя исходные файлы гарнитур поддерживают кириллицу.

`OriginalTypography` проверяет собственную таблицу символов TMP без поиска по fallback. Если русский алфавит, включая Ё/ё, уже присутствует, игровой шрифт сохраняется. Иначе плагин подбирает соответствующую исходную гарнитуру из бандла и создаёт динамический TMP-атлас: размер 90, padding 9, SDFAA, 2048×2048, multi-atlas. Неполный результат не принимается. Для нераспознанных гарнитур используется Montserrat.

18 исходных файлов OTF относятся к ресурсам игры. В публичный Git они не включены. Для локальной сборки:

```powershell
python tools/extract_game_fonts.py "$env:SABLE_GAME_PATH"
```

Скрипт извлекает только файлы из `tools/bundle-fonts.json`, проверяет наличие полного набора и не перезаписывает отличающиеся локальные файлы. Результат сохраняется в исключённой из Git папке `Fonts/Original`. Исходная игра не изменяется.

В бандл входят эти 18 гарнитур и три Montserrat. Наличие в бандле не означает, что все они загружаются и создают TMP-атласы при старте: выбор происходит по используемому игровому шрифту. На старте русского режима заранее готовятся только EuclidFlex Bold и Medium.

`tools/validate_bundle.py` сравнивает Font.m_FontData каждого включённого шрифта с локальным исходником побайтово. Мониторинг шрифтов и тесты логики не заменяют визуальную проверку интерфейса, переносов и типографики внутри игры.
