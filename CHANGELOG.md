# Изменения

## 2.3.1

- Готовый ZIP с BepInEx 6.0.0-pre.1 IL2CPP x64 и Mono для распаковки в корень игры.
- Базовые Unity-библиотеки включены для первого запуска без скачивания; совместимые игровые сборки создаются локально.
- Русский язык выбирается при первом использовании русификатора. Уже сохранённый выбор не заменяется.
- Из бандла исключены семь неиспользуемых CrimsonText/FuturaPT/PlayfairDisplay. Остались три Montserrat и 18 исходных игровых гарнитур.
- Пройдена 91 регрессионная проверка; содержимое бандла и целостность ZIP проверены. Холодный запуск полного архива на чистой игре не выполнялся.

## 2.3.0

- Шрифты, логотипы и единый перевод перенесены в rtlc.bundle.
- Папка установленного русификатора содержит только DLL и бандл.
- Убрана отдельная запись debug_plugin.log; диагностика остаётся в BepInEx.

## 2.2.1

- Добавлена подмена двух логотипов с возвратом оригиналов при переключении языка.

## 2.2.0

- Единый файл translation.txt для интерфейса, предметов и сюжетного Ink.
- Сохранение контекстных идентификаторов, форматирования и управляющей структуры Ink.
